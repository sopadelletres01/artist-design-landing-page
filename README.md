# Cleo Marín

Landing editorial de una sola página para una retratista. El contenido es mock.

## Arranque

```bash
npm install
npm run dev
```

Producción:

```bash
npm run build
npm run preview
```

## Contenido real

Edita solo `src/content/artist.ts` y sustituye los SVG de `public/portraits/` por WebP con el mismo slug. Los componentes no llevan copy.
